Calls to NEAR AI

Every call the server makes for one triage, in order. First it gets an attestation report with a fresh nonce and has NVIDIA check the GPU evidence: no incident data is sent yet. Only when those checks pass does it send the masked evidence to the model, then it fetches the reply's signature. Shown live while it runs; press Replay to step through it again.

Run a triage to see the calls.

Ask the SRE agent

Follow-up questions about this incident. Every message goes through the same path as the triage: secrets masked, the TEE attestation checked with a fresh nonce, and the reply's signature verified. Nothing is kept on the server between messages.
